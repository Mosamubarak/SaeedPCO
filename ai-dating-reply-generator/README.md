# AI Dating Reply Generator (Prototype)

## Wat is dit?
Een simpele web prototype waar je chattekst invoert en direct 3 dating reply suggesties krijgt op basis van mood:
- Standard
- Spicy
- Hot

## Starten
Open `index.html` in je browser.

## Opmerking
- OCR upload is nu placeholder.
- Voor echte AI generatie kun je later een backend endpoint toevoegen.
